# Vini — Portfolio

A single-page, dependency-free portfolio site covering:

- **AI & Software Development** — Polo (health AI), Nova 3.0 Ultimate (Discord bot), AI prototyping, deployment & monitoring
- **Community Leadership & Server Security** — Galaxy network, mergers & treaties, large-scale moderation, anti-nuke architecture
- **Creative Production** — football highlight edits, original soundtracks
- **Gaming Operations** — Minecraft SMP administration, endgame Blox Fruits

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Works as-is on GitHub Pages (Settings → Pages → deploy from branch, root folder), Netlify, Vercel, or Render static sites.
