Apex, an AI co-pilot

A single HTML file that runs my builder-focused system prompt on the Anthropic API. It's direct, it stays in scope, and it has safety limits.

Prototype · no build step

What it does

  • Chat with a co-pilot that keeps answers direct and scoped.
  • Guardrails for destructive commands and health questions.
  • Works in light and dark themes on phone and desktop.

How it's built

  1. You typeA message goes into the chat page.
  2. Prompt attachedEach request carries the Apex system prompt and the conversation so far.
  3. Reply renderedThe reply comes back and appears in the thread as plain text.
